UPLOAD
Upload every file in this ZIP at once, keeping the folders:
  field-guide/index.html     the Field Guide page (now with levels)
  field-guide/codes.js       sealed access codes (no readable codes inside)
  field-guide/lib-owner.js   Owner library, encrypted
  field-guide/lib-staff.js   Staff library, encrypted (the same library as before, moved out of index.html)
  field-guide/lib-field.js   Field library, encrypted (welcome placeholder only)
  tools.html                 "Request access" now opens the Field Guide front door
Nothing to delete.

THE THREE LEVELS
  Owner  (Chris and Kayti)  opens Owner, Staff, and Field. Owner tab: Access manager, private pricing, Organization Playbook (placeholder).
  Staff                     opens Staff and Field. Same Field Guide as before: Guides, People, Library, Training, Safety.
  Field                     opens Field only. A welcome page until Orientation is built. Don't give out Field codes yet.
A code is only typed once, to set up a device. After that each person uses their own passcode.

FIRST STEPS AFTER UPLOAD (in this order)
 1. On your phone, open growwithgrounded.com/field-guide/ and unlock with your passcode.
    It asks once for the Owner code. Type the Owner code from our chat.
 2. Open the Owner tab. Tap "Finish setup." It downloads a new codes.js.
 3. Upload that codes.js to field-guide/ (replace the old one). Reopen the Field Guide.
    You'll see "Your Access manager changes are live."
 4. Kayti: on her device, unlock, then type the Owner code once.
 5. Optional but smart: in the Owner tab, tap Rotate Owner, upload the files it gives you,
    and share the new Owner code with Kayti privately. That retires the code that was in our chat.

THE STAFF CODE
Today's Field Guide code is now the Staff code. It keeps working until you rotate Staff.
When you rotate Staff, the Access manager gives you a new word code.

ACCESS MANAGER (Owner tab)
  Make a code: Organization (Field), Field (individuals), Staff, or Owner. Organization codes end one year out.
  Remove a code: stops new devices using it. Devices already set up keep access until you rotate that level.
  Rotate a level: new key and new code for that level. Use Staff when someone leaves. Use Field for the yearly change.
  Every change is a working copy on your device until you upload the files it gives you (always codes.js, plus a lib file when you rotate).
  Codes you make are kept in your own encrypted records, so you can look them up again in the Owner tab.

HOW IT WORKS (for later sessions)
  Each level's library has its own random key. codes.js holds a sealed copy of a level key for each code (the code itself is never stored),
  plus links that let Owner open Staff and Field, and Staff open Field. Rotating a lower level doesn't bother higher levels: they follow the links.
  Existing devices from before levels open as Staff and are offered the Owner step. Records and notes carry over.
  The page loads codes.js and the lib files fresh on every open, so uploads take effect right away.
